# 오늘 저녁 뭐 먹지 — UI 계획서

> 버전 0.1 · 작성일 2026-11-09 · 관련 문서: [`PLAN.md`](./PLAN.md)

---

## 1. 디자인 원칙

| 원칙 | 의미 |
|---|---|
| **3초 결정** | 앱을 열고 버튼 한 번으로 추천을 받는다. 추천 버튼은 어느 탭에서든 바로 보인다 |
| **이유가 보이는 추천** | 추천 카드에는 항상 "왜?"가 함께 나온다 |
| **한 손 조작** | 자주 쓰는 버튼(추천, 분류 필터, 결정)은 화면 아래쪽 절반에 둔다 |
| **기록은 가볍게** | 결정 버튼을 누르면 기록이 자동으로 채워진다. 사용자는 별점만 주면 된다 |
| **색만으로 구분하지 않기** | 분류는 색 + 아이콘 + 글자를 함께 쓴다 (색약 사용자 배려) |

## 2. 디자인 시스템

### 2.1 색상

| 용도 | 라이트 | 다크 | 비고 |
|---|---|---|---|
| Primary (브랜드) | `#FF6B35` | `#FF8A5C` | 추천 버튼, 강조 |
| Background | `#FFFFFF` | `#121212` | |
| Surface (카드) | `#F8F9FA` | `#1E1E1E` | |
| Text 기본 | `#212529` | `#F1F3F5` | |
| Text 보조 | `#6C757D` | `#ADB5BD` | 거리, 주소 |
| Error | `#E03131` | `#FF6B6B` | |

**분류 색상** (칩, 지도 마커, 달력 점에 공통 사용)

| 분류 | 아이콘 | 색상 |
|---|---|---|
| 한식 | 🍚 | `#F08C00` 주황 |
| 중식 | 🥟 | `#E03131` 빨강 |
| 일식 | 🍣 | `#1C7ED6` 파랑 |
| 양식 | 🍝 | `#2B8A3E` 초록 |
| 기타 | 🍽 | `#868E96` 회색 |

### 2.2 글꼴
- **Pretendard** (무료, 한글 가독성 좋음). 시스템 글자 크기 설정을 따름

| 이름 | 크기 / 굵기 | 사용처 |
|---|---|---|
| Display | 28 / Bold | 추천 식당 이름 |
| Title | 20 / SemiBold | 화면 제목, 상세 식당 이름 |
| Body | 16 / Regular | 목록 식당 이름, 본문 |
| Caption | 13 / Regular | 거리, 주소, 보조 정보 |

### 2.3 간격·모양
- 간격 단위 4px (4 / 8 / 12 / 16 / 24 / 32)
- 화면 좌우 여백 16px
- 카드 모서리 16px, 칩·버튼 모서리 999px(알약 모양), 입력창 12px
- 누를 수 있는 영역은 최소 48×48px

### 2.4 다크 모드
- 1차부터 지원, 기본값은 **시스템 설정 따름**
- 네이버 지도도 다크 모드 지도 스타일로 함께 전환

## 3. 화면 구조

### 3.1 화면 목록

| ID | 화면 | 진입 경로 |
|---|---|---|
| S-00 | 스플래시 | 앱 시작 |
| S-01 | 온보딩 + 위치 권한 | 첫 실행 |
| S-10 | **주변 (목록)** — 첫 화면 | 하단 탭 1 |
| S-11 | 주변 (지도) | S-10 오른쪽 위 전환 버튼 |
| S-12 | 위치 직접 설정 | S-10 위치 이름 누르기 / 권한 거부 시 |
| S-20 | **식당 상세** | 목록·지도·추천·달력에서 식당 이름 누르기 |
| S-30 | **오늘의 추천** | 하단 탭 2 / 주변 화면의 추천 버튼 |
| S-40 | **달력** | 하단 탭 3 |
| S-41 | 그날 기록 목록 (하단 시트) | 달력 날짜 누르기 |
| S-50 | **기록 입력·수정** | 상세의 [기록하기] / 추천의 [여기로 결정] / 달력의 [+] |
| S-60 | **설정** | 하단 탭 4 |
| S-61 | 제외 식당 관리 | 설정 |
| S-62 | 못 먹는 음식 | 설정 |
| S-63 | 백업·복원 | 설정 |

### 3.2 화면 이동도

```
                 ┌──────────── 하단 탭 ────────────┐
 S-00 → (첫 실행) S-01 → ┤ 주변 S-10 │ 추천 S-30 │ 달력 S-40 │ 설정 S-60 │
                 └────┬─────────┬──────────┬──────────┬─────┘
                      │         │          │          ├→ S-61 제외 식당
         ┌────────────┤         │          │          ├→ S-62 못 먹는 음식
         ↓            ↓         │          ↓          └→ S-63 백업·복원
   S-11 지도 ↔ S-10   S-12      │       S-41 그날 기록
         │            위치설정   │          │
         └──────┬───────────────┘          │
                ↓                          ↓
          S-20 식당 상세  ←─────────────────┤
                │  ├→ 네이버 지도 앱 (외부)   │
                │  └→ 카카오 장소 페이지 (외부)│
                ↓                          ↓
          S-50 기록 입력 ←── S-30 [여기로 결정]
```

### 3.3 하단 탭

```
┌─────────┬─────────┬─────────┬─────────┐
│   📍    │   ✨    │   📅    │   ⚙️    │
│  주변   │  추천   │  달력   │  설정   │
└─────────┴─────────┴─────────┴─────────┘
```
- **추천 탭**은 가운데 쪽에 두고 Primary 색으로 강조
- 탭을 바꿔도 각 탭의 스크롤 위치·필터 상태 유지

| 동작 | 결과 |
|---|---|
| 식당 줄 누르기 | **S-20 식당 상세** |
| 식당 줄 왼쪽으로 밀기 | [숨기기] → 제외 목록에 추가 (되돌리기 토스트) |
| 분류 칩 누르기 | 해당 분류만 표시 (하나만 선택) |
| 아래로 당기기 | 새로고침 (위치 다시 확인) |
| 정렬 | 가까운 순 / 안 가본 곳 먼저 / 이름순 |

**상태별 화면**

| 상태 | 표시 |
|---|---|
| 불러오는 중 | 식당 줄 모양의 회색 스켈레톤 6줄 |
| 결과 없음 | "1km 안에 이 분류의 식당이 없어요" + [반경 2km로 넓히기] |
| 인터넷 없음 | "인터넷 연결을 확인해 주세요" + 마지막 캐시 목록(시각 표시) |
| 위치 권한 없음 | "위치를 직접 설정하면 주변 식당을 볼 수 있어요" + [위치 설정] |
| 서버 오류 | "잠시 후 다시 시도해 주세요" + [다시 시도] |

│           ✨                   │

```
┌───────────────────────────────┐
│ 오늘의 추천                ↻   │
├───────────────────────────────┤
│ ┌───────────────────────────┐ │
│ │ 🍚 한식 · 순대국     420m  │ │
│ │ 성수 할매순대국             │ │ ← Display 크기
│ │                           │ │
│ │ 왜 추천하나요?              │ │
│ │ ☔ 비가 오고 9℃라 따뜻한     │ │
│ │    국물 요리가 좋아요        │ │
│ │ 🔄 최근 2번이 양식·일식이라   │ │
│ │    한식으로 바꿨어요         │ │
│ │ 🆕 아직 가 보지 않은 곳이에요 │ │
│ │ 📍 걸어서 6분이에요          │ │
│ │                           │ │
│ │ [상세 보기]  [✔ 여기로 결정] │ │
│ └───────────────────────────┘ │
│                               │
│ 다른 후보                       │
│ ┌────────────┐ ┌────────────┐ │
│ │🥟 진짬뽕    │ │🍚 명동칼국수 │ │ ← 작은 카드, 누르면 큰 카드와 바뀜
│ │380m · 짬뽕  │ │650m · 칼국수│ │
│ │☔ 국물 요리  │ │🆕 처음      │ │ ← 이유 1줄
│ └────────────┘ └────────────┘ │
│                               │
│      [ ↻ 다른 추천 받기 ]        │ ← 지금 3곳은 빼고 다시
└───────────────────────────────┘
```

| 동작 | 결과 |
|---|---|
| ✔ 여기로 결정 | 축하 애니메이션(짧게) → **S-50** (날짜·식당·분류·메뉴·날씨 자동 입력) |
| ↻ 다른 추천 | 지금 보인 3곳을 빼고 다시 계산, 넘긴 곳은 `SKIPPED`로 기록 |
| 상세 보기 | S-20 |
| 큰 카드 좌우로 밀기 | 다른 후보로 전환 |

**추천 중 연출:** 버튼을 누르면 분류 아이콘(🍚🥟🍣🍝)이 0.8초 정도 돌아가는 짧은 애니메이션 → 결과 (실제 계산은 즉시 끝나지만 "고르는 느낌"을 줌, 설정에서 끌 수 있음)

**후보가 적을 때:** "최근 간 곳을 빼니 후보가 4곳뿐이에요. 3일 전 기록까지만 피했어요" 안내

## 5. 주요 사용 흐름

### 흐름 A — 추천 받고 바로 결정 (핵심 흐름, 목표: 3번 누르기)
```
앱 열기 → [✨ 오늘의 추천 받기] → 추천 카드·이유 확인 → [✔ 여기로 결정]
       → 기록 화면(자동 입력) → [저장] → (식사 후) 별점 남기기
```

### 흐름 B — 직접 둘러보고 고르기
```
주변 → [🍣 일식] 칩 → 식당 이름 누르기 → 상세 → [네이버 지도 길찾기]
     → (식사 후) 상세 [오늘 여기서 먹었어요] → 기록 저장
```

### 흐름 C — 지난 기록 보기
```
달력 → 날짜 누르기 → 그날 기록 시트 → 식당 이름 → 상세 (다시 가기)
```

### 흐름 D — 첫 실행
```
스플래시 → 온보딩 → 위치 권한 허용 → 주변 목록
                  └ 거부 → 위치 직접 설정 → 주변 목록
```

## 7. 접근성·기타
- 모든 아이콘 버튼에 스크린리더 라벨 (TalkBack / VoiceOver)
- 시스템 글자 크기를 키워도 레이아웃이 깨지지 않게 (최대 1.3배까지 검증)
- 글자·배경 명암비 4.5:1 이상
- 애니메이션 줄이기 설정이 켜져 있으면 추천 연출 생략
- 진동: 결정 버튼에 가벼운 햅틱
